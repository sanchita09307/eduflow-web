# Changelog

All notable changes to the **EduFlow** project will be documented in this file.

## [1.0.0] - 2026-10-09

### Added
- **Project Scaffolding**: Initialized React 19, TypeScript, Tailwind CSS v4, Lucide icons, and Motion animations.
- **Permanent Progress Tracker**: Established `PROJECT_STATUS.md` with full checklist and requirements mapping.
- **Teacher Command Center**: High-level KPI metrics, active subjects, student group rosters, batch milestone velocity, and pending reviews.
- **Capstone Project Creator**: Multi-milestone configuration, 100% total weightage validator, and multi-group allocation.
- **Student Group Kanban Board**: 4-lane workflow (To Do, In Progress, In Review, Completed), task priority tagging, student roll number attribution, and advance/previous buttons.
- **Deliverables & Versioned Review**: Timestamped file turn-in, multi-version changelog history, faculty rubric grading out of 20 marks, rework requests, and confetti feedback.
- **Explainable Rule-Based Risk Engine**: Evaluates overdue milestones, critical blockers, and activity hiatus to provide diagnostic recommendations.
- **Individual Student Contribution Breakdown**: Non-punitive advisory score calculated from verified task velocity and deliverable authorship.
- **AI Teacher Assistant**: Interactive chat advisor with suggested prompts for viva preparation and batch status.
- **Student Hub**: Dedicated student portal with personal tasks, team deliverables, and teacher remarks.
- **FastAPI Python Backend**: Complete SQLAlchemy 2.0 models, Pydantic schemas, JWT authentication, risk engine, and pytest test suite.
- **Architecture Documentation**: Added `ARCHITECTURE.md`, `DATABASE_SCHEMA.md`, `API_DOCUMENTATION.md`, and `DEVELOPMENT_GUIDE.md`.
